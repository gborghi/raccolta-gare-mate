*Surjective map on unit disk preserving distance implies isometry*

> Seja $D$ o conjunto dos pontos $p$ em $\mathbb{R}^2$ com $|p| \le 1$. Seja $f : D \to D$ uma função sobrejetora satisfazendo $|f(p) - f(q)| \le |p - q|$ para quaisquer $p, q \in D$. Prove que $f$ é uma isometria, isto é, que $|f(p) - f(q)| = |p - q|$ para quaisquer $p, q \in D$.
>
> (Observação: $|(x, y)|$ denota $\sqrt{x^2 + y^2}$.)
