*Iterated absolute-value functions f_{n+1}=|f_n-2|, f_0=|x|; solve f_n(x)=1*

> The sequence of functions $f_n : \mathbb{R} \to \mathbb{R}$ is given by $f_0(x) = |x|$ and, for each $n$,
> $$f_{n+1}(x) = |f_n(x) - 2| \quad \text{for all } x.$$
> Solve the equation $f_n(x) = 1$, where $n$ is a given positive integer.

Le funzioni di valore assoluto <iterate f_{n+1}=li_f_n-2 khi, f_0=li_x khi; risolvere f_n(x)=1*

*Continuous f with some iterate equal to 1 for every x; show f(1)=1*

> Suppose that $f : \mathbb{R} \to \mathbb{R}$ is a continuous function such that for every real $x$ there exists $n \in \mathbb{N}$ such that
> $$\underbrace{f \circ f \circ \cdots \circ f}_{n}(x) = 1.$$
> Show that $f(1) = 1$.

**Metodo:** [[method_backward|Backward]], [[method_invarianti|Invarianti]]

*Continuous f con qualche iterate uguale a 1 per ogni x; mostrare f(1)=1*
