*Max number of 3-cycles in a 14-player round robin*

> When $14$ people play a round-robin tournament of shogi (each person plays exactly one game against each of the other $13$ people), at most how many "three-way cycles" (sansukumi) can there be? Here, a "three-way cycle" means a set of $3$ people satisfying the following condition: among these $3$ people, the results are such that each of the $3$ has exactly one win and one loss. Assume that no game ends in a draw.

Here, two colorings of the disk that can be obtained from one another by rotation are regarded as the same coloring.

```tikz
  \draw (0,0) -- (\a*360/7:2cm);
}
\end{tikzpicture}
```

*Functional equation over rationals; solve f(x)=2002*

> A function $f(x)$ is defined for every rational number and takes rational values, and satisfies the following conditions $(1)$, $(2)$, $(3)$.
> 
> $(1)$ $f(0) = 2,\ f(1) = 3$.
> 
> $(2)$ For any rational number $x$ and any integer $n$, the following holds:
> $$f(x+n) - f(x) = n\{f(x+1) - f(x)\}.$$
> 
> $(3)$ For any nonzero rational number $x$, the following holds:
> $$f(x) = f\left(\frac{1}{x}\right).$$
> 
> Under these conditions, find all rational numbers $x$ satisfying $f(x) = 2002$.

**Topic:** [[topic_funzionali|Equazioni funzionali]]
**Abilita:** [[skill_manipolazione_algebrica|Manipolazione algebrica]], [[skill_astrazione|Astrazione]]
**Area:** [[Algebra e Analisi]]
**Fonte:** [apri PDF](https://drive.google.com/file/d/1WpcMHSRWydHTNqwDM4S4rwTtUxRVnLbW/view)


<span class="qlang-split" data-lang="it"></span>


*Equazione funzionale sui razionali; risolvere f(x)=2002*

> Una funzione $f(x)$ è definita per ogni numero razionale e assume valori razionali e soddisfa le seguenti condizioni $(1)$, $(2)$, $(3)$.
> 
> $(1)$ $f(0) = 2,\ f(1) = 3$.
> 
> $(2)$ Per qualsiasi numero razionale $x$ e per qualsiasi numero intero $n$, il seguente vale: $$f(x+n) - f(x) = n\{f(x+1) - f(x)\}.$$
> 
> $(3)$ Per qualsiasi numero razionale non zero $x$, il valore seguente è: $$f(x) = f\left(\frac{1}{x}\right).$$
> 
> In queste condizioni, trovare tutti i numeri razionali $x$ che soddisfano $f(x) = 2002$.
