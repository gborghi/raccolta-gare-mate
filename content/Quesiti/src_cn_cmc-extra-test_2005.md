*Minimum of symmetric function given linear constraints on positive reals*

> Assume that positive numbers $a$, $b$, $c$, $x$, $y$, $z$ satisfy $cy + bz = a$, $az + cx = b$, $bx + ay = c$. Find the minimum value of the function
> $$f(x, y, z) = \frac{x^2}{1+x} + \frac{y^2}{1+y} + \frac{z^2}{1+z}.$$

**Topic:** [[topic_disuguaglianze|Disuguaglianze]], [[topic_algebra|Algebra]]
**Metodo:** [[method_disuguaglianze|Disuguaglianze]], [[method_simmetria|Simmetria]], [[method_fattorizzazione|Factorisation / algebraic manipulation]]

**Area:** [[Algebra e Analisi|Algebra and analysis]]

*Sum of floor function involving fractional part of square root*

> For each positive integer $n$, define a function
> $$f(n) = \begin{cases} 0, & \text{if } n \text{ is the square of an integer,} \\ \left[\dfrac{1}{\{\sqrt{n}\}}\right], & \text{if } n \text{ is not the square of an integer.} \end{cases}$$
> (Here $[x]$ denotes the maximum integer not exceeding $x$, and $\{x\} = x - [x]$.) Find the value of $\displaystyle\sum_{k=1}^{200} f(k)$.
