*Coloring integers in M with two colors preserving sum condition*

> Let $n$ and $k$ be given relatively prime natural numbers, $k < n$. Each number in the set $M = \{1, 2, \ldots, n-1\}$ is colored either blue or white. It is given that
> (i) for each $i \in M$, both $i$ and $n - i$ have the same color;
> (ii) for each $i \in M$, $i \neq k$, both $i$ and $|i - k|$ have the same color.
> Prove that all numbers in $M$ must have the same color.

*Polynomial with integer coefficients: odd-indexed partial sums are integers*

> For any polynomial $P(x) = a_0 + a_1 x + \cdots + a_k x^k$ with integer coefficients, the number of coefficients which are odd is denoted by $w(P)$. For $i = 0, 1, \ldots$, let $Q_i(x) = (1 + x)^i$. Prove that if $i_1, i_2, \ldots, i_n$ are integers such that $0 \le i_1 < i_2 < \cdots < i_n$, then
> $$w(Q_{i_1} + Q_{i_2} + \cdots + Q_{i_n}) \ge w(Q_{i_n}).$$

**Topic:** [[topic_algebra|Algebra]], [[topic_combinatoria|Combinatoria]]
**Metodo:** [[method_induzione|Induzione]], [[method_congruenze|Congruenze]]

*Sequence defined by recursion has exactly one initial value in (0,1)*

> For every real number $x_1$, construct the sequence $x_1, x_2, \ldots$ by setting
> $$x_{n+1} = x_n \left( x_n + \frac{1}{n} \right)$$
> for each $n \ge 1$. Prove that there exists exactly one value of $x_1$ for which
> $$0 < x_n < x_{n+1} < 1$$
> for every $n$.
