*Quartic with four positive roots implies inequalities on coefficients*

> If the equation $x^4 + px^3 + qx^2 + rx + s = 0$ has four positive real roots, prove that
> 
> (a) $pr - 16s \ge 0$
> 
> (b) $q^2 - 36s \ge 0$
> 
> with equality in each case if and only if the four roots are equal.

**Metodo:** [[method_disuguaglianze|Disuguaglianze]], [[method_simmetria|Simmetria]]

*Find all values of f(1990) for function with given functional properties*

> 
> (i) $x - f(x) = 19\left\lfloor \frac{x}{19} \right\rfloor - 90\left\lfloor \frac{x}{90} \right\rfloor$ for all nonnegative integers $x$;

> (ii) $1900 < f(1990) < 2000$.
> 
> Find all possible values that $f(1990)$ can take.
