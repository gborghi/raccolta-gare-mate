> $N$ is a four-digit integer, not ending in zero, and $R(N)$ is the four-digit integer obtained by reversing the digits of $N$; for example, $R(3275) = 5723$. Determine all integers $N$ such that $R(N) = 4N + 3$.

*Determine value of a1997 in a recursively defined sequence*

> For positive integers $n$, the sequence $a_1, a_2, a_3, \ldots$ is defined by
> $$a_1 = 1, \quad a_n = \left(\frac{n+1}{n-1}\right)(a_1 + a_2 + \cdots + a_{n-1}), \quad n > 1.$$
> Determine the value of $a_{1997}$.

*Three yes/no inequalities for positive x, y with sum conditions*

> Let $x$, $y$ be positive numbers.
> 
> (i) If $x + y \ge 3$, is it necessarily true that $\dfrac{1}{x} + \dfrac{1}{y} \le \dfrac{3}{7}$?
> 
> (ii) If $x + y \ge 3$, is it necessarily true that $\dfrac{1}{x} + \dfrac{1}{y} \le 3$?
> 
> (iii) If $x + y \ge 3$, is it necessarily true that $\dfrac{1}{x} + \dfrac{1}{y} \le 3$?
