*Two internally tangent circles; PQ=QR, radius 9; find PQ*

> Circle $C_1$ contains circle $C_2$ internally, with the two circles internally tangent. Let $O$ be the centre of $C_2$. Let $A$ be the point of internal tangency of $C_1$ and $C_2$. Let $P$ be a point on $C_1$. The ray from $O$ through $P$ meets $C_2$ at point $Q$ (so $Q$ lies between $O$ and $P$). The tangent to $C_1$ at $A$ meets the line $OP$ extended beyond $P$ at point $R$. Given that $PQ = QR$ and that the radius of $C_2$ is $9$, find the length of segment $PQ$. (Here $\overline{XY}$ denotes the length of segment $XY$.)

*Regular octagon vertices labelled 1–8; count arrangements avoiding consecutive-value neighbors*

> A regular octagon has its $8$ vertices each labelled with a distinct integer chosen from $1$ to $8$ (each integer used exactly once). > \item The integers written at any two vertices connected by a \emph{short diagonal} (skipping exactly one vertex) are never consecutive integers.
> \end{itemize}

*Minimo numero di operazioni per ottenere una configurazione bianca e nera*

> \item tutte le caselle della colonna più a sinistra sono nere;
> \item ogni riga che contiene almeno una casella bianca contiene anche una casella nera adiacente (che condivide un lato) a qualche casella bianca;
> \item ogni casella bianca è adiacente ad almeno una casella nera.
> \end{itemize}

*Fill 6×6 array with integers 1–6; two compositional conditions; count valid arrays*

> Write an integer from $1$ to $6$ in each cell of a $6 \times 6$ array $(a_{i,j})$ (where $1 \le i, j \le 6$), with repetition allowed. For each row $i$, define the function $f_i : \{1,\ldots,6\} \to \{1,\ldots,6\}$ by $f_i(j) = a_{i,j}$. Count the number of ways to fill the array so that both of the following conditions hold for all valid indices:
> \begin{itemize}
> \item For every $i$ with $1 \le i \le 6$: $f_i(f_i(j)) = i$ for all $j$ with $1 \le j \le 6$.
> \item For every $i, k$ with $1 \le i, k \le 6$: $f_{f_i(k)}(j) = f_i(f_k(j))$ for all $j$ with $1 \le j \le 6$.
> \end{itemize}
