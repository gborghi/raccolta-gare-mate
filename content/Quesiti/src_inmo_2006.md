*Triangle with AP sides: IO perp BI, I circumcenter of DKE*

> In a non-equilateral triangle $ABC$, the sides $a, b, c$ form an arithmetic progression. Let $I$ and $O$ denote the incentre and circumcentre of the triangle respectively.
> 
> (i) Prove that $IO$ is perpendicular to $BI$.
> 
> (ii) Suppose $BI$ extended meets $AC$ in $K$, and $D$, $E$ are the midpoints of $BC$, $BA$ respectively. Prove that $I$ is the circumcentre of triangle $DKE$.

*Find all integer triples (a,b,c) with functional equation f(f(a,b,c))=(a,b,c)*

> Let $X$ denote the set of all triples $(a, b, c)$ of integers. Define a function $f : X \to X$ by
> $$f(a, b, c) = (a + b + c,\; ab + bc + ca,\; abc).$$
> Find all triples $(a, b, c)$ in $X$ such that $f(f(a, b, c)) = (a, b, c)$.

*Cyclic quadrilateral ABCD with angle 120 degrees: two inequalities*

> In a cyclic quadrilateral $ABCD$, $AB = a$, $BC = b$, $CD = c$, $\angle ABC = 120^\circ$, and $\angle ABD = 30^\circ$. Prove that
> 
> (i) $c \ge a + b$;
> 
> (ii) $|\sqrt{c + a} - \sqrt{c + b}| = \sqrt{c - a - b}$.

*Find integer l with n < l^2 < (1+1/2005)n for n >= 4011^2*

> (a) Prove that if $n$ is a positive integer such that $n \ge 4011^2$, then there exists an integer $l$ such that
> $$n < l^2 < \left(1 + \frac{1}{2005}\right)n.$$
> 
> (b) Find the smallest positive integer $M$ for which whenever an integer $n$ is such that $n \ge M$, there exists an integer $l$ such that
> $$n < l^2 < \left(1 + \frac{1}{2005}\right)n.$$

*Trova l'intero numero con n < l^2 < (1+1/2005)n per n >= 4011^2*
