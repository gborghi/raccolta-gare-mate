*Number of solutions of cyclic quadratic system via discriminant*

> Consider the system of equations
> $$ax_1^2 + bx_1 + c = x_2$$
> $$ax_2^2 + bx_2 + c = x_3$$
> $$\cdots$$
> $$ax_{n-1}^2 + bx_{n-1} + c = x_n$$
> $$ax_n^2 + bx_n + c = x_1,$$
> with unknowns $x_1, x_2, \ldots, x_n$, where $a, b, c$ are real and $a \neq 0$. Let $\Delta = (b-1)^2 - 4ac$. Prove that for this system
> 
> (a) if $\Delta < 0$, there is no solution,
> 
> (b) if $\Delta = 0$, there is exactly one solution,
> 
> (c) if $\Delta > 0$, there is more than one solution.

**Metodo:** [[method_casework|Analisi per casi]], [[method_simmetria|Sfruttamento della simmetria]], [[method_ricorsione|Recursion]]

**Fonte:** [apri PDF p.1](https://drive.google.com/file/d/1jj0Y7JrXtrt_wCg-LIs-qk4WRobE3ZR1/view)

*Prove functional equation implies f periodic; give example*

> Let $f$ be a real-valued function defined for all real numbers $x$ such that, for some positive constant $a$, the equation
> $$f(x + a) = \frac{1}{2} + \sqrt{f(x) - [f(x)]^2}$$
> holds for all $x$.
> 
> (a) Prove that the function $f$ is periodic (i.e., there exists a positive number $b$ such that $f(x + b) = f(x)$ for all $x$).
> 
> (b) For $a = 1$, give an example of a non-constant function with the required properties.

**Topic:** [[topic_funzionali|Equazioni funzionali / successioni]], [[topic_trigonometria|Trigonometry]]
**Metodo:** [[method_trigonometria|Trigonometric techniques]]
**Abilita:** [[skill_astrazione|Astrazione / generalizzazione]], [[skill_manipolazione_algebrica|Algebraic manipulation]]
**Area:** [[Algebra e Analisi|Algebra and analysis]], [[Geometria|Geometry]]
**Fonte:** [apri PDF p.1](https://drive.google.com/file/d/1jj0Y7JrXtrt_wCg-LIs-qk4WRobE3ZR1/view)

> (b) Per $a = 1$, fornisci un esempio di funzione non costante con le proprietà richieste.

> (The symbol $\lfloor x \rfloor$ denotes the greatest integer not exceeding $x$.)
