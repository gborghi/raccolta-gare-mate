*Sequence whose first n terms sum to zero and which is periodic with period n; prove some starting index N makes all partial sums from N nonnegative*

> A sequence $(a_k)_{k=1}^{\infty}$ has the property that there is a natural number $n$ such that $a_1 + a_2 + \cdots + a_n = 0$ and $a_{n+k} = a_k$ for all $k$. Prove that there exists a natural number $N$ such that
> $$\sum_{i=N}^{N+k} a_i \ge 0 \quad \text{for } k = 0, 1, 2, \ldots.$$

**Metodo:** [[method_estremalita|Estremalità]]

*Sequenza la cui prima n termini somma a zero e che è periodica con il periodo n; dimostrare che qualche indice iniziale N rende tutte le somme parziali da N non negative*

*Find smallest positive alpha for which some beta>0 gives sqrt(1+x)+sqrt(1-x)<=2-x^alpha/beta on [0,1], and the smallest such beta*

> Find the smallest positive number $\alpha$ for which there is a positive number $\beta$ such that for all $0 \le x \le 1$,
> $$\sqrt{1+x} + \sqrt{1-x} \le 2 - \frac{x^{\alpha}}{\beta}.$$
> For each such $\alpha$ determine the smallest $\beta > 0$ for which this condition holds.

*Trova il più piccolo alfa positivo per il quale qualche beta>0 dà sqrt(1+x)+sqrt(1-x)<=2-x^alpha/beta su [0,1], e il più piccolo beta*

*Characterize when a triangle with one angle alpha admits circumradius R and inradius r: iff 2R/r >= 1/(sin(alpha/2)(1-sin(alpha/2)))*

> Show that it is possible to circumscribe a circle of radius $R$ about, and inscribe a circle of radius $r$ in some triangle with one angle equal to $\alpha$, if and only if
> $$\frac{2R}{r} \ge \frac{1}{\sin \frac{\alpha}{2} \left(1 - \sin \frac{\alpha}{2}\right)}.$$

*Given S(x)=1-x and T(x)=x/2 on [0,1], does a composition f=g1 o ... o gn of these satisfy f(1/2)=1975/2^1975?*

> On the interval $[0,1]$ are given functions $S(x) = 1 - x$ and $T(x) = x/2$. Does there exist a function of the form $f = g_1 \circ g_2 \circ \cdots \circ g_n$, where $n \in \mathbb{N}$ and each $g_k$ is either $S(x)$ or $T(x)$, such that
> $$f\left(\frac{1}{2}\right) = \frac{1975}{2^{1975}}?$$
